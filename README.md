# 文色

**—— 把文字里的心情，变成可以观看和收藏的颜色。**

文色是一款 AI 辅助的情绪视觉互动原型。输入一句心情或一段经历，AI 分析其中的情绪，程序将结果转化为渐变色卡、柔和粒子和人格标签。

项目由本人独立完成，涵盖交互设计、前端开发、模型 API 接入与功能迭代。

## 功能体验

- **生成整体色卡：** 输入文字或点击示例，查看情绪配色、占比和人格标签。
- **观看情绪分镜：** 输入有明确情绪转折的经历，通过简短旁白、渐变色彩和粒子动画观看情绪变化，支持暂停、切幕和重播。
- **探索情绪收藏馆：** 收集人格与探索成就，点击卡片查看解锁线索或历史色卡。

## 技术实现

| 部分 | 实现 |
| --- | --- |
| 前端界面 | HTML、CSS、JavaScript |
| 情绪分析 | 通过模型 API 获取六种基础情绪占比、情感极性及分镜内容 |
| 视觉呈现 | 程序根据分析结果生成渐变配色、粒子动画和人格标签 |
| 请求管理 | 输入防抖与会话缓存，减少重复分析和 API 请求 |
| 输出校验 | 校验模型 JSON、数值及分镜原文来源；无效分镜保留整体分析并使用单幕呈现 |
| 本地启动 | Python 标准库提供配置工具与本地 HTTP 服务 |

## 启动方式

需要 **Python 3.8 或更高版本**、浏览器，以及可用的模型 API Key；无需安装额外 Python 依赖。

1. 下载并解压项目，进入包含 `start.bat` 的文件夹。
2. 双击 `start.bat`，按提示填写以下三项：

   | 配置 | 填写内容 |
   | --- | --- |
   | Endpoint | 模型服务的完整聊天接口 URL，例如 `https://open.bigmodel.cn/api/paas/v4/chat/completions` |
   | API Key | 对应服务的 API 密钥，输入时不显示字符 |
   | Model | 所选服务支持的准确模型 ID |

3. 配置完成后，脚本启动本地服务并自动打开浏览器。
4. 使用期间保留命令行窗口，按 `Ctrl+C` 或关闭窗口停止服务。下次启动可按回车复用已有配置。

首次运行需填写完整配置，项目不预置固定模型。可接入兼容 Chat Completions、Bearer 鉴权及 JSON 输出格式的模型服务；切换服务时应同时修改 Endpoint、API Key 和 Model。

启动配置会写入本地的 `assets/engine/ai.js`。上传或分享项目时，应将 API Key 恢复为占位符。

## 项目结构

| 路径 | 内容 |
| --- | --- |

| `assets/session.js` | 会话分析缓存 |

| `start.py` | Python 配置与本地服务工具 |

## 项目背景

项目原型来自本人的小红书 `vibe coding` 大赛作品。本次迁移将核心体验与平台限制分离，以独立网页运行，并接入可配置的 AI 模型。

在保留原有配色、人格标签和海报设计的基础上，新增“情绪分镜”，通过简短旁白、渐变色彩与粒子动画呈现情绪变化，共同构成可观看、可收藏的情绪互动体验。
