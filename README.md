# 文色

**—— 把文字里的心情，变成可以观看和收藏的颜色。**

文色是一款 AI 辅助的情绪视觉互动原型。输入一句心情或一段经历，AI 分析其中的情绪，程序将结果转化为渐变色卡、柔和粒子和人格标签。

## 启动方式

需要 **Python 3.8 或更高版本**、浏览器，以及可用的模型 API Key；无需安装额外 Python 依赖。

1. 解压项目，双击 `start.bat`。
2. 按提示填写以下三项后，脚本自动打开浏览器

   | 配置 | 填写内容 |
   | --- | --- |
   | Endpoint | 模型服务的完整聊天接口 URL，例如 `https://open.bigmodel.cn/api/paas/v4/chat/completions` |
   | API Key | 对应服务的 API 密钥，输入时不显示字符 |
   | Model | 模型名称，项目默认是 `glm-5.3-flash` |

3. 使用期间保留命令行窗口，按 `Ctrl+C` 或关闭窗口停止服务。下次启动可按回车使用已有配置。


>GLM 只是默认选择，也可接入兼容 Chat Completions、Bearer 鉴权及 JSON 输出格式的其他服务。切换服务时应同时修改 Endpoint、Key 和 Model。

!!!API Key 会保存在本地 `ai.js` 中，分享项目之前请将其改回 `YOUR_API_KEY`。

## 怎么玩

- **生成整体色卡：** 输入文字或点击示例，查看情绪配色、占比和人格标签。 
- **观看情绪分镜：** 输入有明确情绪转折的经历并观看，支持暂停、切幕和重播。 
- **探索情绪收藏馆：** 收集人格与探索成就，点击卡片查看解锁线索或历史色卡。 

## 项目背景

项目原型来自小红书 `vibe coding` 大赛作品。本次迁移将核心体验与平台限制分离，以独立网页运行，并接入可配置的 AI 模型。

在保留原有配色、人格标签和海报设计的基础上，新增“情绪分镜”，通过简短旁白、渐变色彩与粒子动画呈现情绪变化，共同构成可观看、可收藏的情绪互动体验。
